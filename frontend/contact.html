Project Repository

Dengbêj AI is an open project. The most reliable way to reach the project — to report a mistake, suggest a source, or ask a question — is by opening an issue on the public GitHub repository: github.com/arslakin/dengbej-ai.

Reporting a Correction

Because summaries and translations are AI-generated, mistakes happen. When you report one, it helps to include the story, what was inaccurate, and what it should say. See Transparency for how corrections are handled.

Report a correction on GitHub

This opens a new issue on the public GitHub repository. GitHub may ask you to sign in or create a free account before you can post.
