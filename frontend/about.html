About Dengbêj

The story behind the storyteller.

What is a Dengbêj?

A dengbêj is a traditional Kurdish oral storyteller. For generations, dengbêjs have been the voice of their communities — recounting histories, delivering news from distant villages, and preserving collective memory through song and spoken word.

The dengbêj tradition is particularly strong in the Kurmanji-speaking regions. Without written archives, these storytellers carried entire histories in their voices, performing in gathering houses called "dîwanxane" where communities would come together to listen.

Today, as Kurdish language faces challenges in many regions, the dengbêj tradition represents both cultural resistance and continuity — a reminder that stories survive through telling.

About This Project

Dengbêj AI uses generative AI to create Kurdish news radio programs from current events. It fetches global news, summarizes and translates stories into Kurdish Kurmanji, and generates audio narration — all automatically, twice daily.

Built for the AWS 10,000 AIdeas Weekend Challenge, this project demonstrates how serverless architecture and foundation models can serve under-resourced languages and preserve cultural traditions in new forms.

AWS Services Used

  • Amazon BedrockStory summarization, Kurdish translation, and broadcast script generation using foundation models.
  • Amazon PollyEnglish narration audio synthesis for daily news programs.
  • AWS LambdaServerless compute for all pipeline stages — ingestion, curation, translation, and audio generation.
  • Amazon DynamoDBStorage for articles, briefings, and program data with fast key-value access.
  • Amazon EventBridgeScheduled pipeline automation triggering ingestion and curation on a fixed cadence.
  • Amazon S3Audio file storage for generated narration clips.
  • AWS AmplifyStatic frontend hosting with custom domain and continuous deployment.

Roadmap

  • Kurdish TTS narration when high-quality Kurmanji voices become available
  • More news sources beyond BBC, DW, and Al Jazeera
  • Event-driven architecture for real-time breaking news
  • Community contributions for translation quality review
  • Regional dialect support (Sorani, Zazaki)
